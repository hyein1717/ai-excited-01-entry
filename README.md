Entry for the [make.fun](https://make.fun/bounty/ai-excited-01) "Make the AI judge excited" bounty (ai-excited-01).

A single deterministic Python 3 program (standard library only) that draws one
image: a colossal blue whale breaching out of a tiny glass fishbowl — deep teal
water, a radial glow, a splash crown, and warm golden rim light. The picture is
built to read instantly, even at thumbnail size.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) into the output directory. The
output is byte-identical on every run.
